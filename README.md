# ☕ Cafe Ordering System

A simple command-line Cafe Ordering System built with **Python** using **Object-Oriented Programming (OOP)** concepts.

## 🚀 Features

- Display cafe menu
- Add drinks to the order
- View current order
- Calculate total price
- Checkout and confirm the order
- Clear the order after successful checkout
- Handle invalid user input

## 🛠️ Technologies

- Python 3
- Object-Oriented Programming (OOP)
- Command Line Interface (CLI)

## 📚 OOP Concepts Used

### Classes & Objects
The project uses two main classes:

- `Drink` — represents a drink with its name and price.
- `Order` — manages the customer's order and its operations.

### Encapsulation
Order-related data and operations are grouped inside the `Order` class.

### Methods
The project uses methods such as:

- `add_item()`
- `calculate_total_price()`
- `show_order_summary()`
- `checkout()`

## ▶️ How to Run

Make sure Python 3 is installed.

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cafe-ordering-system.git
```

Navigate to the project:

```bash
cd cafe-ordering-system
```

Run the program:

```bash
python main.py
```
